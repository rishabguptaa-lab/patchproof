# Contributing

1. Open an issue describing the failure mode and a minimal vulnerable example.
2. Add both a positive and a negative fixture. A rule without a false-positive test will not be accepted.
3. Run `npm run check` before opening a pull request.
4. Keep findings evidence-based: every message must explain what was observed, why it is exploitable, and how to fix it.

By contributing, you agree that your contribution is licensed under Apache-2.0.
